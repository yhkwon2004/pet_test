# INFU RETRO 홍보 영상: 편집용 패키지

완성본은 `INFU-RETRO_홍보영상.mp4`입니다. 사양은 1920×1080, 30fps, 96초이고 음악과 알림음이 들어 있습니다.

## 방법 1. 영상 편집 프로그램에서 고치기 (Premiere Pro · DaVinci Resolve)

1. 압축을 풀고 폴더 구조는 그대로 둡니다. 위치는 어디든 괜찮습니다.
2. 타임라인 파일 `edit/INFU-RETRO_promo_timeline.xml`을 가져옵니다.
   - **Premiere Pro:** 파일 → 가져오기 → xml 선택
   - **DaVinci Resolve:** File → Import → Timeline 선택
     - 창에서 *Automatically set project settings*를 켜세요(1920×1080 · 30fps).
3. 미디어가 오프라인으로 뜨면 다시 연결합니다. 모든 영상 · 음악 · 효과음이 `edit/media` 폴더 하나에 있습니다.
   - **Premiere:** 미디어 연결 창에서 `edit/media/scene_s1.mp4`를 지정하고 *나머지 자동 재연결*을 켭니다.
   - **Resolve:** *Relink Media*에서 `edit/media` 폴더를 지정합니다.
4. 트랙 구성:
   - **V1 (켜짐):** 장면 9개가 각각 완성된 클립입니다. 순서 바꾸기 · 길이 자르기는 여기서 합니다.
   - **V2 · V3 (꺼짐, 고급용):** 제품 공개(0:17–0:27)와 실제 시연(0:33–0:53)을 레이어로 나눈 것입니다.
     - V2는 아래에 깔리는 영상입니다. `bg_s3.mp4`가 조립 렌더, `bg_s5.mp4`가 시연 촬영입니다.
     - V3은 그 위의 투명 그래픽 `gfx_s3.mov` · `gfx_s5.mov`입니다.
     - 영상 속도나 컷을 바꾸려면 V2 · V3 트랙을 켜고 V2의 영상을 편집하세요.
     - Resolve에서 그래픽 배경이 투명하지 않게 보이면 클립 속성 → Alpha Mode를 *Straight*로 바꿉니다.
5. 오디오: A1은 배경 음악 `music.wav`, A2는 알림음입니다.
   - 알림음은 시연의 알림 3번과 협약 합계 1번에 각각 따로 놓여 있어서, 장면을 옮길 때 함께 옮기면 됩니다.
6. 자막: `edit/captions.srt`를 가져온 뒤 타임라인으로 끌어 놓으면 자막 트랙이 생기고, 글자를 바로 고칠 수 있습니다.

> 배경 음악과 알림음은 이 패키지에서 직접 합성한 것이라 저작권 문제가 없습니다. 원하는 음악으로 바꿔도 됩니다. 시연 영상의 원래 소리는 뺐습니다.

## 방법 2. 화면 속 글자 · 숫자 · 배치를 고치기

화면 그래픽은 모두 `src/scenes.html` 한 파일에서 만들어집니다.

1. `scenes.html`을 메모장이나 VS Code로 열고 각 `<section>` 안의 글자를 고칩니다.
2. 타이밍 관련 속성:
   - `data-t0` · `data-t1`: 장면의 시작 · 끝(초, 영상 전체 기준)
   - `data-a`: 장면 시작 기준으로 나타나는 시각(초)
   - `data-d`: 나타나는 데 걸리는 시간(초, 클수록 느림)
   - `data-out`: 장면 시작 기준으로 사라지는 시각(초)
   - `data-fx`: 효과 종류(up · left · right · scale · fade · zoom · draw · count)
3. 미리 보기: 브라우저로 `scenes.html?t=20`을 열면 20초 시점 화면이 보입니다.
4. 다시 만들기: Node.js, ffmpeg, Python 3(numpy)가 필요합니다.
   1. 처음 한 번 `npm i playwright`와 `npx playwright install chromium`을 실행합니다.
   2. `src` 폴더에서 `node render.cjs`를 실행합니다.
   3. 이어서 `python3 build.py`를 실행합니다.
   - 자막 · 알림음 시각은 장면 기준으로 계산되므로, 장면 길이를 바꿔도 따라갑니다.
   - `build.py`는 `captions.srt`와 타임라인 xml을 새로 씁니다. 자막 문구는 `build.py`의 `SUBS`에서 고치세요.
   - 시연 컷 구간은 `build.py`의 `CUTS`에서 정합니다.

## 사용한 자료 · 근거

- **실제 자료:** 시연 영상, 하우징 조립 렌더, 시제품 · 모듈 · PCB 사진, 수상 사진 · 상장, 약정서 · 협약서는 모두 INFUTECH 자료입니다.
  - 약정서 · 협약서는 공개 영상용으로 제목만 남기고 나머지(대표자 · 사업자번호 · 주소 · 날인)를 흐리게 처리했습니다.
  - 도입부 밤 입원실 이미지만 연출 이미지이고, 화면에 그렇게 표시했습니다.
- **수치 출처:**
  - 카테터 합병증 26.7%: Haskey 2024 · 영국 19개 기관 · 정맥염 포함
  - 확인 간격 1~2시간: AAHA 2024
  - 1인 수의사 비율: 농식품부 2025.6 (5,312곳 중 3,815곳)
  - 오차 · 감지 성능: 내부 모의시험(모의 병실 1,000회)
  - 수상: 산업통상부 「청년 뉴턴(NEW:TURN) 2026」 (2026.11.19)
- **약정 · 협약 표기:**
  - 약정은 KC 인증 후 효력이 생기고, 협약은 비구속입니다. 화면에 "확정 매출 아님 · 부가세 별도"로 표시했습니다.
  - 전남대 수의과대학 LOI는 합계에서 뺐습니다.
  - 휴대폰 알림 도착 시간은 실측 전이라 "즉시"라고 쓰지 않았습니다.
