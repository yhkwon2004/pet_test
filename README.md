# INFU RETRO IR — 레퍼런스 스타일 (WON SHOT)

반려동물 수액 이상감지 모듈 **INFU RETRO**의 IR 웹 덱입니다. `index.html` 한 파일로 열리고, 대본 기준 4분 30초입니다.

- 디자인: 인디고 → 화이트 그라데이션 · 흰 카드 · 핵심 숫자 원형 강조 · 장당 핵심 메시지 하나
- 근거: 각 장 하단 출처 · 계약서 · 기사 캡처 · 시험 사진 · 논문 원문 이미지
- 발표 노트: 각 장 `<div class="note">` (화면의 노트 버튼)

## 보기

`index.html`을 브라우저로 열면 됩니다(←/→ 이동). 정적 파일이라 서버가 필요 없습니다.

## 스크립트

- `scripts/script-time.py` — 대본 음절 수 · 장별 시간
- `scripts/subset-font.py` — 사용 글자만 담은 Pretendard 서체를 `index.html`에 내장
- `scripts/charts.py` — 차트 SVG 생성(일부 장에서 사용)

## PowerPoint

`export/INFU-RETRO_IR_WON-SHOT.pptx` — 웹 덱 21장을 그대로 담은 16:9 파일(시연 영상 2개 자동 재생 · 발표 노트에 대본). 다시 만들려면:

```
npm i playwright pptxgenjs sharp jszip
node scripts/build-pptx.cjs . export/INFU-RETRO_IR_WON-SHOT.pptx
```

`export/INFU-RETRO_IR_WON-SHOT_editable.pptx` — **편집형**. 글자(약 470개)는 PowerPoint 텍스트 상자, 사진은 그림 개체, 도표·아이콘(SVG)은 투명 PNG, 시연 영상은 동영상 개체로 올라가고, 카드 · 그라데이션 · 막대 같은 배경만 슬라이드 배경 그림으로 깔립니다. 서체는 Pretendard(설치 권장 — 없으면 비슷한 서체로 대체되어 줄 길이가 조금 달라질 수 있음).

```
node scripts/build-pptx-editable.cjs . export/INFU-RETRO_IR_WON-SHOT_editable.pptx
```
