# INFU RETRO IR — 레퍼런스 스타일 (WON SHOT)

반려동물 수액 이상감지 모듈 **INFU RETRO**의 IR 웹 덱입니다. `index.html` 한 파일로 열리고, 대본 기준 4분 30초입니다.

- 디자인: 인디고 → 화이트 그라데이션 · 흰 카드 · 핵심 숫자 원형 강조 · 장당 핵심 메시지 하나
- 근거: 각 장 하단 출처 · 계약서 · 기사 캡처 · 시험 사진 · 논문 원문 이미지
- 발표 노트: 각 장 `<div class="note">` (화면의 노트 버튼)
